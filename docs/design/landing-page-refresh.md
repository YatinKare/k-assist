# Landing page refresh

The two entry points live in a persistent bottom dock. The dock uses a precomputed, rounded-edge displacement map with an SVG backdrop filter in Chromium; CSS blur and an opaque tint provide progressive fallbacks. User preferences disable refraction, motion, or transparency. Labels sit above the filtered layer. The page reserves bottom space and safe-area insets for the dock.

References: [Kube’s refraction explanation](https://kube.io/blog/liquid-glass-css-svg/), [shuding’s liquid-glass demo](https://github.com/shuding/liquid-glass), [Lucide for Svelte](https://lucide.dev/guide/svelte/getting-started), and [Chrome Modern Web Guidance](https://developer.chrome.com/docs/modern-web-guidance). Retrieved guides: `form-factor-adaptation`, `visual-effects`, and `prevent-page-scroll-under-modal-dialog`.

Typography uses the self-hosted Manrope variable font (OFL). Monochrome icons use `@lucide/svelte` (ISC). Services support hover, focus, click/tap, arrow-key navigation, Home, and End. On narrow screens, the illustration remains sticky above the service list.

## Artwork

Both assets were produced with the built-in image generation tool, inspected, and encoded as WebP at quality 86. The service illustration is a six-scene atlas, so switching tasks does not require another network request. Final assets: `apps/marketing/static/service-worlds.webp` and `apps/marketing/static/cloud-path.webp`.
